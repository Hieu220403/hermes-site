Hermes Agent — Personal Automation

A private, single-user automation tool. Not a public product.

What this application does

This application connects to a single Google Account — the account of its owner — and automates routine personal workflow tasks:

  • Reading the owner's own email to sort messages into labels and summarise what needs attention.
  • Creating and updating calendar events, such as job interviews extracted from confirmation emails.
  • Drafting replies for the owner to review before they are sent.

Who uses it

One person: the owner of the account that authorises it. The application is not distributed, not published to any app store, and has no other users.

Data handling

Data is read only from the authorising account, processed on infrastructure controlled by the owner, and never sold, transferred, or shared with third parties. The application does not use Google user data to train or improve any machine learning model, and does not use it for advertising. See the Privacy Policy for details.
