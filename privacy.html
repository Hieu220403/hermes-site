Privacy Policy

Hermes Agent — personal automation tool · Last updated: 15 November 2026

This policy explains how the Hermes Agent personal automation tool ("the application") accesses, uses, stores, and shares Google user data. It applies to a single private installation operated by one individual — the account holder who authorises it. The application is not offered to the public and has no other users.

1. Google user data the application accesses

  • Gmail: message headers, message bodies and attachment names, read and labelled within the authorising account only, plus the ability to create drafts and send messages on the owner's behalf when the owner approves them.
  • Google Calendar: the owner's calendar events, to read availability and to create, update or delete events.
  • Google Drive, Docs and Sheets: files created by or belonging to the owner, used to store tracking spreadsheets and documents produced by the automation.
  • Basic profile: the account email address, used to identify the account.

2. How the data is used

Data is used solely to perform the tasks the owner requests: sorting and summarising the owner's inbox, extracting dates and details from messages to schedule calendar events, drafting replies for the owner's review, and maintaining the owner's own tracking documents. No data is used for advertising, profiling, sale, or any purpose unrelated to those tasks.

3. Storage and security

OAuth tokens are stored on a server controlled by the owner, in files readable only by the owner's system account. Message content is processed in memory; only data the owner explicitly asks to keep (such as a tracking row in a spreadsheet) is persisted. Credentials are never shared, and access can be revoked at any time from the owner's Google Account permissions page.

4. Sharing with third parties

The application does not sell, rent, transfer, or disclose Google user data to any third party. No data is shared with advertisers, data brokers, or analytics providers.

Limited Use disclosure. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used to develop, improve, or train generalised or non-personalised machine learning or artificial intelligence models.

5. Retention and deletion

Data is retained only as long as it is useful to the owner, and can be deleted on request or by the owner at any time. Revoking the application's access in the Google Account permissions page stops all further access immediately. To request deletion of any data held, contact the address below.

6. Changes to this policy

Any material change to how Google user data is handled will be reflected on this page with an updated date before the change takes effect.
